更新策略

这里只控制更新行为，不上传也不保存 APK。

Panel 控制
自动跟随 Latest Release开启后，Android 优先通过 Panel 获取最新正式版本。
强制更新仅在检测到新版本时生效。普通版本建议保持关闭。
推荐流程：Android 编译完成 → GitHub 创建正式 Release → 上传 APK 与 SHA256SUMS.txt → Panel 自动同步。无需把 APK 上传到 Panel。

Android 接口

公开版本元数据接口，不需要登录 Token；不返回用户、节点或管理数据。

API v1
GET /api/v1/app/update?version_name=0.1.0&version_code=10009
优先级Android 先请求 Panel，Panel 不可用时再走 GitHub fallback。 校验Panel 只接受带 APK + SHA256SUMS.txt 的完整 Latest Release。 缓存GitHub 临时异常时继续返回最后一次成功快照，并标记 stale。
